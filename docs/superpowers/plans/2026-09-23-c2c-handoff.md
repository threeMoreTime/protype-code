# C2C 本地材料交接实施计划

> 执行依据：用户已批准材料包方案并要求开始执行。Required skill: executing-plans，逐项执行并验证；不提交、不推送。

目标：保留未修改的原版 C2C，用其本地 session/record 保存摘要，通过人工审核的普通对话材料包与网页端 6 Pro 协作。不启用 MCP，不绕过管理员权限，不自动发送消息或执行 GPT 文本。

实现采用 Node 内置模块，无新依赖、服务或 API 密钥。输入、输出和状态固定在本项目 `.local/handoff/`，C2C 镜像状态独立存放。源业务仓库完全不参与本轮测试。

## 步骤和验证

- [x] 复现停止脚本的 `--json` 参数错误，按上游命令能力修复；执行 stop/status，检查监听端口及 cloudflared 进程。
- [x] 先编写 Node 测试：显式文件清单、目录穿越/链接/敏感内容拦截、任务和轮次摘要绑定、人审门禁、过期/重复/不完整回复拒绝、重启恢复。
- [x] 实现 `scripts/c2c-handoff.mjs`：smoke/build/status/approve/sent/import/decision/sync。任何来自 GPT 的指令只能作为待确认建议存档。
- [x] 使用独占锁和原子状态文件防止并发覆盖；C2C 写入前标记同步开始，出现不确定结果停止重试，防止重复记录。
- [x] 在临时合成夹具内实际调用固定版本 C2C 的 session set/get 与 record；不启动桥接、不修改上游源码。
- [x] 通过全部测试后生成合成草稿，保留 DRAFT 状态，不代替用户声明已经审核或发送。
- [x] 更新操作指南、原范围与桥接记录；根据 requesting-code-review 技能安排只读审查，并处理重要问题。

初版本地交付结果：16 组测试通过，独立只读复核 Ready。后续用户单独授权 Agent 完成合成网页往返，并确认本地回复无问题；授权操作主体标签补充后的回归为 17 组通过，任务已记录 DECIDED/accepted。真实业务材料发送不包含在合成测试授权内。

验证命令：`node --test scripts/c2c-handoff.test.mjs`；`node scripts/c2c-handoff.mjs smoke`；`node scripts/c2c-handoff.mjs status c2c-smoke`；`./scripts/c2c.ps1 -Command status`。

## 人工验收门槛

用户阅读合成材料后，在实际显示 6 Pro 的普通 ChatGPT 对话中发送；返回完整正文，经本地关联校验存档。模型选择和发送成功仅记录人工观察，不由脚本推断。GPT 应区分提供的事实与缺失证据，不能声称独立读取了仓库。

本轮本地实现完成不等于网页端闭环完成，也不等于完成产品重设计。真实业务材料在人工合成验收之前不发送。若普通对话共享同样受组织政策禁止，则停止交接。
