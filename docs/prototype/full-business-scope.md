# 三应用全业务、完整双端交付基线

需求基线确认于 2026-10-16。本文记录三应用全业务、完整双端与 17 个语种的产品目标，替代旧计划中“成员管理、场地预约、文章浏览”三个业务代表样例的范围。旧样例和已有实机证据保留为技术回归；其通过结果不代表本基线已经实现。

当前已有离线生成入口和共享演示实现，可生成离线 HTML、演示数据与 Figma 设计规格。这不表示全部模块、全部 17 个语种、桌面与移动端或真实 Figma 验收已经完成；未验收项继续记录为 `NOT RUN`。

## 本地使用

在仓库根目录运行，输出目录须不存在：

```powershell
npm run prototype:business -- --out prototype-output/business-v1
npm run prototype:business -- --out prototype-output/cs-admin-mobile-ar --app cs-admin --device mobile --locale ar
```

HTML 保留三应用和全部 17 个语种；`--app`、`--device`、`--locale` 选择初始入口和导出的设计规格。

## 目标与参考范围

## 共享数据与业务真实性

代表主链为咨询 → 提交客服反馈 → 客服受理与沟通 → 升级关联工作流 → 工单办理与补充材料 → H5补全 → 工作流结束 → 客服结束反馈并邀评 → H5评价；同时全量覆盖各模块的独立操作和异常，不能由主链代替其他模块验收。

- 客服反馈、工作流工单、流程实例分别保留ID，通过显式关联连接。
- 客服反馈、整单、节点、个人参与、工单结束、邀评、评价分别保存状态。
- 聊天会话评价与工单服务评价分别建模，保留各自分值协议。
- 适用创建人编辑入口的工作流工单被拒绝后，结束当前办理轮次；创建人修改原单并显式重新发起，保留上一轮历史，双端一致。客服升级来源的专有限制继续按其业务入口处理。

- 新轮次重新初始化已激活、待执行、等待和已完成节点集合；上一轮分支与任务仅保留为历史，不能阻塞修改条件后的新分支。
- 已关闭客服反馈保持原记录；继续反馈走关联新单，不能与工作流重发规则混用。
- 新增、编辑、删除、认领、流转、配置发布等实际更新演示记录；列表、详情、待办、统计及时间线共享同一数据来源。
- 配置需要影响对应下游，例如知识问答、公告、表单、接单规则、团队排班、流程和机器人版本。失败、取消、越权和版本冲突不得悄悄修改记录。

- 流程图发布和执行共用实际目标边：校验 next、并行 branches 及条件分支 target 的引用与循环；顺序流程和既有内联并行节点保持原有语义。编辑配置时，显式清空可选文本或关联会保存空字符串，清空可选数字或日期时间会保存 null；未修改的字段继续省略，创建表单的可选空值和必填校验保持原样。
- 保存与加载应恢复记录、配置、版本、关联和演示媒体；附件不能仅保存本次浏览器临时URL。

## 离线能力与输出边界

完整业务在HTML中执行。AI、机器人真实接口、翻译服务、通知、跨系统网络同步、上传服务、宿主和发布操作采用明确标注的离线演示响应，具备可复现的成功、失败及结果不明分支。配置和本地规则实际生效；模拟结果不得标为真实外部服务接入。

全部使用虚构身份、记录、媒体与连接描述，不复制真实客户数据、凭据、签名链接和存储密钥。角色切换及权限演示不代表真实账号鉴权。

交付包含离线HTML、可保存/加载的演示数据、语义规格及需求追踪、可编辑Figma设计、原生交付与验收证据。参考工程是业务依据；本轮没有新增“自动生成生产应用工程或真实后端”的目标。

Figma需要覆盖相应双端页面、状态及声明交互；真实表单输入、记录修改和业务计算由HTML验收，不能以Figma点击成功页代替业务通过。

## 17语种与双端验收

语言全集：简体中文 `zh_cn`、繁体中文 `zh_tw`、英语 `en`、日语 `ja`、韩语 `ko`、法语 `fr`、俄语 `ru`、泰语 `th`、越南语 `vi`、马来语 `ms`、印尼语 `id`、阿拉伯语 `ar`、西班牙语 `es`、葡萄牙语 `pt`、意大利语 `it`、德语 `de`、土耳其语 `tr`。

三应用的双端均纳入全部17语种验收，包括导航、字段、动态文案、校验、状态、日期数字、长文本、布局和业务配置联动；阿拉伯语覆盖RTL。切换语言码但文案大量回退、布局溢出或业务内容错配，不能记为通过。

完整双端意味着每个模块可完成其对应操作。流程/表单设计器、机器人、权限树、排班、长表格、配置和媒体均须提供可用的移动操作，不能用不支持提示代替。

浏览器行为、各端布局、各语种、Figma结构和字体、PNG、Present、原生`.fig`导出与独立回导分别记录 `PASS / FAIL / NOT RUN`。源码存在、局部响应式或一次构建通过不能替代任何运行验收。
