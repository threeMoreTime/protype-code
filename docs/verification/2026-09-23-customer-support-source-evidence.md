# 客服客户端源码证据摘要

本记录概述一轮只读静态取证的公开边界。内部仓库名称、源文件路径、精确文件数、机器路径、版本快照、私有材料指纹和会话轨迹不随公开副本发布。

## 范围

检查目标是玩家侧移动 H5 的相关功能事实，包括导航、FAQ、反馈、动态表单、本地化和宿主兼容性。材料经过人工筛选和脱敏，只用于支持设计讨论；没有复制完整源码或锁文件。

## 证据等级

- **VERIFIED**：相关静态源码与配置声明已核对。
- **INFERRED**：从多个静态实现片段推导出的流程，需要后续运行验证。
- **OBSERVED**：在交接或浏览器流程中实际看到的状态。
- **NOT RUN**：业务项目安装、构建、启动、测试、真实接口、宿主或设备验证未执行。

## 保留的产品事实

既有功能涉及聊天、FAQ、反馈和提交、公告等玩家侧入口。组件或类型声明存在不代表入口必然可达，也不证明动态字段、附件、权限、状态迁移和所有语言版本在运行时有效。导航、评价触发和提交落点等跨页面行为应在设计冻结前继续核验。

## 交接与数据边界

只向外部协作提供经审查的脱敏摘要。原始源码、真实用户数据、私有服务地址、认证材料、机器路径、未审查截图和本地运行记录不属于公开证据。模型回复保持为待人工审核的建议；静态证据和回复摘要都不自动授权实施。

## 验证限制

这是一份静态证据摘要，不是完整接口审计、全状态枚举、浏览器验收或生产集成报告。公开材料不包含私有源码哈希或会话级校验值。任何未列出直接运行证据的行为都应视为 **NOT VERIFIED**。
