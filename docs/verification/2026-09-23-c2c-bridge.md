## 操作入口

在 protype-code 根目录用 PowerShell：

```powershell
./scripts/c2c.ps1 -Command status
./scripts/c2c.ps1 -Command start --tunnel
./scripts/c2c.ps1 -Command pair
./scripts/c2c.ps1 -Command stop
```

这些是历史桥接操作入口，当前不要运行 start/pair。`stop` 已实测：初次因包装脚本无条件追加上游不支持的 `--json` 失败；修复本地包装后停止成功，status 返回 running:false，48765 无监听，未发现 cloudflared 进程。unpair 同样不再附加 --json，但撤销命令未执行。

临时隧道已停止，不配置开机启动或后台自动恢复；没有可依赖的固定公网地址。

撤销接入时，先执行 `unpair` 撤销本桥接令牌，再 `stop`，ChatGPT 侧删除连接须另行确认。未执行撤销。
