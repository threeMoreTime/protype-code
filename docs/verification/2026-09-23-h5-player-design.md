# 玩家侧 H5 设计候选摘要

## 范围

面向玩家使用的客服 H5，聚焦 FAQ、聊天、我的反馈、反馈详情与提交体验；不覆盖坐席后台或运营管理界面。设计应保留既有导航和跨页入口，未核实的流程标为待确认。

## 设计方向

可探索以“找答案、继续对话、查看反馈”组织玩家一级任务，并将详情和提交页面保持聚焦。候选方案参考简体中文移动端布局，在 390×844 主视口下整理，并额外检查窄屏、长文案、RTL 和安全区适配。此方向是候选，不是已冻结规格。

静态事实提示：公告返回目标、聊天退出后的评价入口、动态表单条件和成功落点应与实际实现核对。图像生成结果和对话建议不能替代源码证据或运行验证。

## 验证状态

**VERIFIED**：只读静态材料已用于梳理导航、反馈和表单相关事实。精确源文件、路径、数量、摘要和会话信息不公开。

**NOT RUN**：业务项目安装、构建、测试、真实接口或宿主验证；Figma 文件导入、原型连线与完整交互验收。

原型与正式产品分开。公开记录不含 Figma 文件链接、文件身份、节点编号、会话链接或具体授权历史。任何实际设计写入都应由具体任务授权并在写入前检查目标和范围。
