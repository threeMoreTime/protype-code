# 交互原型验证

## 范围与边界

原型覆盖“我的反馈”“反馈详情”和“提交反馈”流程，采用浅色简体中文界面与 390×844 移动视口，展示页面跳转、状态切换、校验提示和模拟提交结果。

原型在专用测试设计文件中通过可见 UI 创建。没有使用 Figma MCP 或隐藏接口，没有改变共享权限，也没有修改正式产品设计文件。全部业务内容均为模拟数据；演示字段不代表真实 schema 或必填规则。不连接真实业务接口，不读取或上传真实玩家图片，也不涉及客服客户端业务仓库的写入。

## 初版三页

- 我的反馈默认态。
- 反馈详情可回复态。
- 提交反馈示例填写态。

三张主画板均为 390×844。通过剪贴板导入 SVG 中间材料后，Figma 生成可编辑的 Frame、分组、矢量和原生文字图层。首个中文测试文字显示 Text/Typography 与字号 20，证实该路径不是整页位图。没有宣称设计系统、Auto Layout 或组件体系已完成。

## 初版播放验证

- PASS：我的反馈第一条记录 → 反馈详情。

- PASS：提交反馈按钮 → 提交表单。

返回路径由原型内部导航完成；不外推宿主退出、深链返回或真实路由行为。原型访问链接未公开。

### 配置回查与播放

逐项检查热点的目标状态，并在浏览器播放页核对 22 条点击导航：

- PASS L0：处理中 → L1；第一条 → D0；提交反馈 → F1。
- PASS L1：全部 → L0；第一条 → D0；提交反馈 → F1。
- PASS D0：补充信息 → D1；返回 → L0。
- PASS D1：回复 → D0；返回 → L0。
- PASS F1：模拟未填写 → F0；模拟提交 → FS；返回 → L0。
- PASS F0：标题和描述载入示例填写态；模拟提交 → FE；返回 → L0。
- PASS FE：标题和描述载入示例填写态；再次提交停留在当前状态；返回 → L0。
- PASS FS：返回我的反馈 → L0；再次演示 → F1。

两条连续主路径均已播放：

- A：L0 → L1 → D0 → D1 → D0 → L0。
- B：L0 → F1 → F0 → FE → F1 → FS → L0。

FE 再点提交保留原提示，不叠加弹层；填写区域载入预置内容后，红色示例提示消失。FS 返回后仍为三条模拟记录。截图观察到八种状态的对应视觉内容，列表和详情首条均为示例 A01。

抽查了 L0 筛选和其他记录、D0 回复展示区、F1 图片展示区；没有出现真实输入或上传界面。此为抽查，不声称遍历所有留白和展示控件。

播放期间记录 43 次操作，包含复验及展示区抽查。一条返回动作的首次即时读取尚未更新；后续截图和稳定状态确认已经返回 L0。此时序事实保留为观察结果，不解释为产品故障。

返回采用固定导航到 L0，不保留筛选或历史栈。FE 的重复提交是无动作停留，不模拟真实校验函数。所有成功状态、字段和提示均标注为演示内容。
